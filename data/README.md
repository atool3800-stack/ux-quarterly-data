# Africa Manufacturing UX — Quarterly Data (Q3 2026)

Africa-region manufacturing UX interaction log repository for **South Africa** and **Egypt** factories.

## Contents (`data/`)

| File | Description |
|------|-------------|
| `manufacturing_ux_africa_q3_2026.csv` | Main interaction log (CSV, 10,000+ records) |
| `manufacturing_ux_africa_q3_2026.json` | Same interaction log in JSON format |
| `data_dictionary.json` | Field definitions and supplementary explanation |

## Scope

- **Period:** 2026-07-01 to 2026-09-30 (Q3 2026)
- **Regions:** South Africa (Johannesburg, Durban, Cape Town, Pretoria plants) & Egypt (Cairo, Alexandria, 10th of Ramadan City, Port Said plants)
- **Sources:** Workshop device operation UI (HMI), internal Manufacturing Execution System (MES), employee feedback platform
- **Key user journeys:** Device startup (设备启动), Work order query (工单查询), Alarm handling (报警处理), Quality recording (质量记录), Report export (报表导出)

## Key metrics

Per journey and region: error rate, response time, retry count (repeated operations), and user abandonment rate.

## Data quality

The raw data contains some missing values, duplicate records, and anomalous fields. These are documented in the quarterly analysis report produced in Notion.
